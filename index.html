What this is

A manifest and a set of small JavaScript files. Each one knows how to read a public website and turn it into chapters. The list is unsigned, so any reader that installs it will say so — that label is accurate and you should believe it.

What this is not

This is not Kuma, and nobody who works on Kuma runs it, endorses it, or vouches for what any listed site hosts. Nothing here stores, mirrors or serves a single page of manga — the files only describe how to read sites that already exist, and your device talks to those sites directly.

No warranty of any kind. Sites break, disappear, and change hands without notice. Use what you have the right to use, and support the people who make the work.

Contents: github.com/yomibako/sources. Open an issue there if a source has broken.
